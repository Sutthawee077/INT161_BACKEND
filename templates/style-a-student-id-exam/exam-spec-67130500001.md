## 🎯 1. การตั้งค่าโครงงานและระบบระบุตัวตน (Setup & Student Identity)

### 1.1 นำเข้าฐานข้อมูล
1. รันไฟล์ SQL นำเข้าฐานข้อมูล:
   ```bash
   mysql -u root -p < database/init-database.sql
   ```
2. ตรวจสอบการตั้งค่าการเชื่อมต่อใน `src/configs/db-config.js` ให้ตรงกับเครื่องของนักศึกษา (Database: `mobile_distributor`)

### 1.2 กำหนดรหัสประจำตัวใน `src/app.js`
ให้นักศึกษากำหนดตัวแปร `ID` หรือ `STUDENT_ID` ในไฟล์ `src/app.js` ดังนี้:

```javascript
const STUDENT_ID = '67130500001';
```

และตั้งค่า Routing ทั้งหมดภายใต้ Base Path: `/api/67130500001/...`

## 🌐 2. รายการ Endpoints เฉพาะของนักศึกษา (Customized Endpoints)

ทุก Endpoint ในข้อสอบของนักศึกษาจะต้องใช้ Base Path ที่มีรหัสนักศึกษา `67130500001` เสมอ

### 2.1 ระบบระบุตัวตน (Identity Verification) - 10 คะแนน
* **Method:** `GET`
* **Endpoint:** `/api/67130500001/student-info`
* **Response Status:** `200 OK`
* **JSON Body:**
```json
{
  "success": true,
  "data": {
    "studentId": "67130500001",
    "name": "Kanokphon Sueby",
    "secretKey": "67KaSu"
  },
  "timestamp": "2026-10-08T15:00:00.000Z"
}
```

---

### 2.2 บริการข้อมูลแบรนด์สินค้า (Brands API) - 10 คะแนน

#### [GET] รายการแบรนด์ทั้งหมด
* **Endpoint:** `/api/67130500001/brands`
* **Status:** `200 OK`
* **Response Body:**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "name": "Apple",
      "country_of_origin": "United States",
      "website": "https://www.apple.com",
      "is_active": 1,
      "created_at": "2024-01-01T00:00:00.000Z"
    }
  ],
  "timestamp": "2026-10-08T15:00:00.000Z"
}
```

#### [GET] ข้อมูลแบรนด์ตามรหัส ID
* **Endpoint:** `/api/67130500001/brands/:id`
* **Status:** `200 OK` (พบข้อมูล) หรือ `404 Not Found` (ไม่พบข้อมูล)

---

### 2.3 บริการข้อมูลสินค้าและสต็อก (Products API) - 65 คะแนน

#### 1) [GET] รายการสินค้าแบบแบ่งหน้าและแปลง DTO (30 คะแนน)
* **Endpoint:** `/api/67130500001/products`
* **Query Parameters:**
  * `page`: หมายเลขหน้า (เริ่มต้นที่ 1, ค่า default คือ 1)
  * `limit`: จำนวนรายการต่อหน้า (เช่น 10)
* **การแปลง DTO (Summary DTO):**
  ข้อมูลใน `data` จะต้องแสดงเฉพาะฟิลด์สรุป:
  * `id`
  * `sku`
  * `name`
  * `brandId` (หรือ `brand_id`)
  * `category`
  * `price`
  * `status`
* **Response Body:**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "sku": "APL-IP15PM-256-NT",
      "name": "iPhone 15 Pro Max",
      "brandId": 1,
      "category": "FLAGSHIP",
      "price": 48900.00,
      "status": "AVAILABLE"
    }
  ],
  "pagination": {
    "total": 75,
    "page": 1,
    "limit": 10,
    "totalPages": 8,
    "hasNextPage": true,
    "hasPrevPage": false
  },
  "timestamp": "2026-10-08T15:00:00.000Z"
}
```

---

#### 2) [GET] ดูรายละเอียดสินค้าตาม ID (Detail DTO) (10 คะแนน)
* **Endpoint:** `/api/67130500001/products/:id`
* **Status:** `200 OK` เมื่อพบสินค้า หรือ `404 Not Found` หากไม่พบ
* **Response Body (Detail DTO):**
```json
{
  "success": true,
  "data": {
    "id": 1,
    "sku": "APL-IP15PM-256-NT",
    "name": "iPhone 15 Pro Max",
    "brandId": 1,
    "brandName": "Apple",
    "category": "FLAGSHIP",
    "price": 48900.00,
    "ramGb": 8,
    "storageGb": 256,
    "color": "Natural Titanium",
    "stockQuantity": 15,
    "status": "AVAILABLE",
    "releaseDate": "2023-09-22"
  },
  "timestamp": "2026-10-08T15:00:00.000Z"
}
```

---

#### 3) [POST] เพิ่มสินค้าใหม่ (10 คะแนน)
* **Endpoint:** `/api/67130500001/products`
* **Status:** `201 Created` เมื่อบันทึกสำเร็จ หรือ `409 Conflict` เมื่อ SKU ซ้ำ
* **Request Body:**
```json
{
  "sku": "TEST-SKU-999",
  "name": "Test Phone 2026",
  "brand_id": 1,
  "category": "FLAGSHIP",
  "price": 29900.00,
  "ram_gb": 8,
  "storage_gb": 256,
  "color": "Black",
  "stock_quantity": 10,
  "status": "AVAILABLE",
  "release_date": "2026-01-01"
}
```

---

#### 4) [PUT] แก้ไขข้อมูลสินค้า (10 คะแนน)
* **Endpoint:** `/api/67130500001/products/:id`
* **Status:** `200 OK` เมื่อแก้ไขสำเร็จ หรือ `404 Not Found` หากไม่พบ ID

---

#### 5) [DELETE] ลบสินค้า (5 คะแนน)
* **Endpoint:** `/api/67130500001/products/:id`
* **Status:** `204 No Content` (ไม่มี Response Body) หรือ `404 Not Found` หากไม่พบ ID

## 🧪 3. คำสั่งทดสอบระบบด้วยตนเองแบบ Offline (Self-Testing)
